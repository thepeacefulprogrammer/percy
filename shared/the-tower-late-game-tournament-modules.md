# The Tower: Late-Game Tournament Module Rolls

Updated: 2026-10-12

This is a practical late-game tournament reference for **natural epic modules at Ancestral 5★**.

## Important rule

At **Ancestral 5★**, the **unique effect uses the Ancestral value**. Stars increase the module's level cap and main effect, but **do not increase the unique-effect number beyond Ancestral**.

Because of that, the best rerolls are chosen by **slot** and **build**, not by the unique module name alone.

---

## Default late-game tournament picks by slot

These are the safest default picks for a strong late-game tournament account.

- **Cannon:** Death Penalty
- **Armor:** Anti-Cube Portal
- **Generator:** Pulsar Harvester or Galaxy Compressor
- **Core:** Dimension Core

### Situational swaps

- **Cannon:**
  - **Havoc Bringer** if your build is heavily centered on Rend scaling.
  - **Amplifying Strike** if your tournament runs maintain strong elite/boss kill uptime.
- **Armor:**
  - **Space Displacer** if you have major Inner Land Mine investment.
  - **Wormhole Redirector** for regen/tank variants.
- **Generator:**
  - **Galaxy Compressor** if package-driven UW cycling is central to your run.
  - **Project Funding** if your tournament setup reliably turns cash scaling into meaningful damage.
- **Core:**
  - **Om Chip** for Spotlight-centered boss damage setups.
  - **Harmony Conductor** if poison miss chance is more valuable than Chain Lightning shock stacking.
  - **Multiverse Nexus** only if your synced cooldown math is specifically better for your account.

## Generator (default late-game tournament utility set)

Best 8 substats:

1. **Enemy Health Level Skip** — 8%
2. **Enemy Attack Level Skip** — 8%
3. **Package Chance** — 15%
4. **Recovery Amount** — 10%
5. **Max Recovery** — 1.5
6. **Free Utility Upgrade** — 12%
7. **Free Defense Upgrade** — 12%
8. **Free Attack Upgrade** — 12%

### Generator notes

- For late-game tournament, **ELS** and **package-based survivability/tempo** matter more than coin stats.
- This set is the best broad default for **Galaxy Compressor**, **Pulsar Harvester**, and many late-game defensive tournament setups.
- **Package Chance** gets extra value when using **Galaxy Compressor** because every package cuts UW cooldowns.
- **Free Upgrades** also improve **Black Hole Digestor** value if you ever switch to it.

### Damage-leaning Generator alternate

Use this if your tournament build values direct damage scaling more than defensive consistency:

- Enemy Health Level Skip — 8%
- Enemy Attack Level Skip — 8%
- Package Chance — 15%
- Recovery Amount — 10%
- Max Recovery — 1.5
- Free Attack Upgrade — 12%
- Free Utility Upgrade — 12%
- Interest / Wave — 8% or Free Defense Upgrade — 12%

In practice, **Free Defense Upgrade** is usually the safer tournament pick.

## Core (default Dimension Core tournament set)

Best 8 substats for a strong late-game tournament account:

1. **Chrono Field Speed Reduction** — 15%
2. **Chrono Field Duration** — 10s
3. **Chrono Field Cooldown** — -10s
4. **Spotlight Bonus** — 20
5. **Spotlight Angle** — 15
6. **Chain Lightning Chance** — 15%
7. **Chain Lightning Damage** — 250x
8. **Smart Missiles Damage** — 250

### Core notes

- This is the strongest default late-game tournament set for a **Dimension Core** account that is using major endgame UWs.
- **Chrono Field** stats are premium tournament rolls because control and survival scale hard in late waves.
- **Spotlight** remains elite because it multiplies focused boss and priority-target damage.
- **Chain Lightning** stats gain major value with **Dimension Core** because of doubled shock chance/multiplier and stacking.

### Core swaps by account

If your tournament account is built differently, use these swaps:

- Swap **Smart Missiles Damage** for **Smart Missiles Cooldown (-6s)** if missile cadence is more important than hit size.
- Swap a missile stat for **Death Wave Quantity (3)** or **Death Wave Cooldown (-13s)** if your build leans hard on Death Wave.
- Swap a CL stat out for **Poison Swamp Duration (10s)** only if you are specifically using **Harmony Conductor** and poison is central to your control plan.
- If using **Om Chip**, keep **Spotlight Bonus** and **Spotlight Angle** as premium priorities.
- If you do not rely on Chrono Field in your tournament setup, CF duration/cooldown can be downgraded in favor of your strongest active UW lines.
